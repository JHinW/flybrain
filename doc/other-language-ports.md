# FlyBrain: other-language versions and related projects

Search date: 2026-10-15. Source: GitHub search and API metadata only. The code of these repositories was not inspected.

`JHinW/flybrain` is a fork of [snedea/flybrain](https://github.com/snedea/flybrain) (JavaScript, 176 stars). Most of its forks are unmodified copies, so GitHub reports no language for them.

## Ports and rewrites of FlyBrain

| Repository | Language | Notes |
|---|---|---|
| [zhuhaozoo/FlyBrain-HarmonyOS](https://github.com/zhuhaozoo/FlyBrain-HarmonyOS) | ArkTS | Native HarmonyOS app. Runs the 139,255-neuron connectome on a phone with ArkGraphics 3D. |
| [leparlon/flybrain](https://github.com/leparlon/flybrain) | GDScript | Godot plugin, modeled on WormBrain. |
| [mehrantsi/flyBrain](https://github.com/mehrantsi/flyBrain) | Rust | No description. Content not verified. |
| [Jhongdlp/FlyBrain](https://github.com/Jhongdlp/FlyBrain) | Rust, Python, TypeScript | Game boss driven by the fly connectome (MaleCNS). Rust engine, Three.js visualizer. |
| [useless-husband/flybrain](https://github.com/useless-husband/flybrain) | JavaScript | Traditional Chinese fork with a synaptic learning playground. |

## Related Python projects (independent implementations)

- [vshapenko/flypoke](https://github.com/vshapenko/flypoke): laptop-speed LIF simulation of the full FlyWire connectome.
- [dylankainth/flybrain](https://github.com/dylankainth/flybrain): fruit fly brain on a drone.
- [freeman-1984-coder/flybrain-sdk](https://github.com/freeman-1984-coder/flybrain-sdk): CPU-only LIF simulation SDK.
- [annel0/flybrain](https://github.com/annel0/flybrain): GPU simulator for connectome-constrained spiking models.
- [dohun1214/flybrain](https://github.com/dohun1214/flybrain): FlyWire LIF driving a NeuroMechFly v2 body.

## Notes

- Within this repo, non-JavaScript code is supporting only: Swift (`ios/`), Python (`scripts/build_connectome.py`), shell scripts.
- The repo readme says the project descends from [heyseth/worm-sim](https://github.com/heyseth/worm-sim) (C. elegans).
